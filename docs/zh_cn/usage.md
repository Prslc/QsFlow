# 使用说明

覆盖层只有一个输入框。输入即搜索；当某个插件拥有输入的第一个词作为前缀时，会路由到该插件，
否则整段输入作为应用/命令查询（见 [plugins.md](plugins.md)）。结果是若干行，`Enter` 作用于高亮行。

## 前缀

| 输入 | 操作 |
| --- | --- |
| `firefox` | 模糊搜索已安装应用 |
| `b <关键词>` | 搜索 Firefox 书签 |
| `h <关键词>` | 搜索 Firefox 历史 |
| `f <关键词>` | 按文件名搜索 |
| `d <关键词>` | 按路径搜索（多词模糊） |
| `r <关键词>` | 模糊搜索 `$PATH` 可执行文件并运行 |
| `w <关键词>` | 切换到匹配的打开窗口 |
| `c <关键词>` | 搜索剪贴板历史 |
| `s <关键词>` | Google 搜索建议 |
| `?` | 显示关键词模式、默认功能与提示 |
| `lock` / `reboot` / `shutdown` | 系统命令 |
| `2 + 3` | 即时计算 |
| *(留空)* | 展示高频使用项 |

## 按键

| 按键 | 操作 |
| --- | --- |
| `Enter` | 打开选中结果 |
| `↑` / `↓` | 移动选择 |
| `PageUp` / `PageDown` | 按页移动 |
| `Home` / `End` | 光标移到查询开头/结尾 |
| `Ctrl+A` | 全选查询内容 |
| `Shift+←/→` | 扩展选区 |
| `Ctrl+C` / `Ctrl+X` | 将选区复制到剪贴板 |
| `Ctrl+V` | 粘贴 |
| `Delete` | 删除选中的历史条目 |
| `Esc` | 关闭 |
